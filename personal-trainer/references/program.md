# 16-Week Periodized Program

**Model:** block periodization (accumulation → intensification → conversion to power → realization), 4 × 4-week blocks.
**Frequency:** 4 lifting sessions a week of about 30 minutes each, plus an optional day-5 recovery session. Rec hockey and golf count as conditioning; they don't replace lifting days.
**Session template (30 min):** 5 min RAMP warm-up → Superset A (~9 min) → Superset B (~9 min) → Superset C (~6 min).
**Supersets:** do A1, then A2, rest, and repeat for the prescribed rounds. Pairs are non-competing (lower + core, push + pull) so rest stays short without hurting quality.
**Deloads:** weeks 4, 8 and 12: one set fewer, loads −15%, RPE 6. **Week 16** is test week: the last set of each main lift is AMRAP at the week-1 load, to measure progress.

## Blocks

| Block | Weeks | Focus | Main lift | Accessory | Rest |
|---|---|---|---|---|---|
| 1 Foundation | 1–4 | Work capacity, tendon tolerance, patterns | 3 × 10–12 @ RPE 7 | 3 × 10–12 | 45–60 s |
| 2 Strength | 5–8 | Heavier main lifts | 4 × 6–8 @ RPE 8 | 3 × 8–10 | 45–60 s |
| 3 Power-Strength | 9–12 | Contrast pairs: heavy set → explosive set | 3 × 4–6 @ RPE 8 | 3 × 6–8 | 90 s after the power set |
| 4 Athletic Peak | 13–16 | Keep the main lifts heavy through the end of the cut; density work is in the accessories | 3 × 5–6 @ RPE 8 | 3 × 10–12 | 30–75 s |

Load progression within a block: about +3% a week (wk1 → wk3), then deload. At a block change, the last logged load carries over, scaled by the ratio of the block factors (it doesn't reset to the plan). Block multipliers on base load: main ×1.00 / 1.15 / 1.25 / 1.20, accessory ×1.00 / 1.08 / 1.12 / 1.05.

Warm-up (5 min): 90/90 switches, world's greatest stretch, hip airplanes, prone Y-T raises (no weight), neck 4-way isometrics, pogo hops, then 2 ramp-up sets of A1.

**Logging:** each exercise has one row per set (checkbox, load, reps). The exercise checks itself off when all its sets are done. Record the RPE of the last set; the next suggestion uses it.

**Why these choices:** the Copenhagen plank, Nordic curls (fresh, on knee day) and lateral lunges protect the adductors (groin strains are the most common hockey injury). Rotational med-ball work, chops, lifts and SL-RDLs carry over to clubhead speed and shot power. Landmine pressing and face pulls keep shoulders healthy through a season of hauling gear. Skater bounds add frontal-plane power. 90/90 hip internal-rotation lift-offs restore lead-hip IR for the golf downswing.

## In-season rules (Nov–Mar runs alongside the NHL season)
- **Road week minimum:** 3 sessions, in priority order D1 → D3 → D2. Drop D4 first.
- **Floating deload:** move the deload into the heaviest travel week instead of keeping it fixed at weeks 4/8/12.
- **Two red readiness days in a row:** do a 2-set week.
- **Rec hockey counts as D4's conditioning.** Skip the bike intervals on weeks with 2 or more games.
- **Week 16 test:** work up to a top set of 3–5 reps at RPE 9 on squat, trap-bar deadlift and pull-up, then estimate 1RM (Epley).

## Autoregulation
- **Readiness** (Athlytic recovery %, or the app's HRV/RHR/sleep model): green ≥67 train as written; yellow 34–66 drop the last round and cap at RPE 7; red <34 do D5 instead.
- **Game day (rec hockey):** a D1/D3 lower session is fine in the morning if the game is in the evening, but skip the jumps. No lower session the morning after a late game; move D4 instead.
- **Golf day:** do rotation work (D2) at least 24 h before a round, not the same morning.
